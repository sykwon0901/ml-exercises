# Applied Machine Learning Exercises

This repository contains selected hands-on exercises from the **Machine Learning** coursework completed as part of the **Applied Data Science Master's program**. Each notebook focuses on the practical application of key machine learning and statistical modeling techniques using Python.

---

## 1. Objective
The goal of this collection is to apply machine learning theories to real-world inspired problems and demonstrate essential skills in modeling, evaluation, and visualization.

## 2. Exercises Overview

| Notebook | Topic | Methods and Models |
|----------|-------|--------------------|
| `Kernels and Regularization.ipynb` | Classification with Kernels | SVM with Polynomial and RBF Kernels |
| `Random Projection.ipynb` | Dimensionality Reduction | Sparse Random Projection (SRP) |
| `Expectation-Maximization.ipynb` | Latent Variable Models | EM Algorithm with Poisson Mixture |
| `MCMC.ipynb` | Probabilistic Modeling | Bayesian Inference on SIRD using MCMC |

## 3. Key Methods and Techniques
- **Supervised Learning:** Classification with Support Vector Machines
- **Dimensionality Reduction:** Sparse Random Projection (SRP)
- **Latent Variable Models:** Expectation-Maximization (EM) for Mixture Models
- **Bayesian Inference:** Markov Chain Monte Carlo (MCMC) with PyMC
- **Visualization & Interpretation:** Decision boundaries, parameter convergence plots, uncertainty intervals

## 4. Tools & Libraries
- **Python** (Jupyter Notebook)
- **scikit-learn**
- **PyMC**
- **Matplotlib & Seaborn**
- **NumPy & Pandas**

Each notebook is self-contained and includes both code and results. The focus is on applying machine learning methods to practical examples while explaining key concepts through visualizations and model evaluation.
